# Simple Calculator

## About the Project
This is a simple calculator application designed to perform basic arithmetic operations. It is a beginner-friendly project created to practice programming logic and improve coding skills.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Simple and user-friendly interface

## Technologies Used
- Python

## How to Run
1. Clone this repository.
2. Open the project in your code editor.
3. Run the Python file.
4. Enter the numbers and select the operation to calculate the result.

## Learning Outcomes
- Understanding basic arithmetic operations
- Practicing conditional statements
- Improving problem-solving skills
- Learning how to build a simple project
